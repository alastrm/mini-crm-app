# Mini CRM

REST API для учёта звонков организациям и встреч с менеджерами.
Python 3.12+, FastAPI, Pydantic и встроенный SQLite. Интерфейс не требуется.
Проверено на Python 3.12.10; версии зависимостей закреплены в `requirements.txt`.

Готовы запуск приложения, схема БД, два тестовых менеджера с ID `1` и `2`,
документация `/docs`, создание и список организаций. Остальные маршруты,
проверки встреч, примеры HTTP-запросов и итоговый `REFLECTION.md`
будут добавлены на следующих этапах. Это ещё не полное решение.

## Установка и запуск

Откройте терминал в папке проекта. Нужен установленный Python 3.12 или новее.
Зависимости устанавливаются в отдельное окружение; активировать его не нужно.

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app
```

Linux / macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app
```

После установки для запуска нужна только последняя команда.
Документация API: <http://127.0.0.1:8000/docs>.
Для остановки нажмите `Ctrl+C`.

## База данных

При запуске приложение выполняет `schema.sql`. Таблицы создаются только
при отсутствии, существующие данные сохраняются. Менеджеры добавляются
только при отсутствии их ID.

- `companies`: название, уникальный БИН из 12 цифр, телефон, статус.
- `managers`: два тестовых менеджера.
- `meetings`: организация, менеджер, текущее и первоначальное время встречи,
  время создания записи, статус.
- `calls`: организация, результат звонка, связанная встреча, время записи.

`CRM_DB_PATH` задаёт путь к SQLite-файлу. По умолчанию это `crm.sqlite3`
в текущей папке. Если указываете вложенную папку, создайте её заранее.
Пример для PowerShell перед запуском:

```powershell
$env:CRM_DB_PATH = "local.sqlite3"
```

Пример для Linux / macOS:

```bash
export CRM_DB_PATH="local.sqlite3"
```

Соединение включает проверку внешних ключей и ждёт освобождения занятой БД
до 5 секунд. Файлы базы исключены из Git.

## Проверки

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Linux / macOS:

```bash
.venv/bin/python -m pytest -q
```

Тесты проверяют запуск, сохранение данных после перезапуска, создание
организаций, пагинацию, валидацию, повторный БИН и сохранение SQL-текста
как обычных данных. Каждый тест использует отдельный временный файл БД
и не меняет рабочую базу. Проверки встреч будут добавлены позже.

Установленная версия Starlette выводит предупреждение о будущем отказе
от `httpx` в `TestClient`. Тесты проходят; предупреждение не скрыто.

## Организации

`POST /companies` принимает `name`, `bin` и `phone`. БИН — строка из 12 цифр;
начальные нули сохраняются. Название и телефон не могут быть пустыми.
Пробелы по краям строк удаляются. Формат телефона дополнительно не ограничен.
Создание возвращает `201`, повторный БИН — `409`, неверные данные — `422`.

`GET /companies` возвращает `items`, `total`, `page`, `page_size`.
Параметр `status` необязателен: `new`, `no_answer`, `refused`, `meeting_set`.
Страница начинается с `1`, размер по умолчанию `20`, максимум `100`.
Номер страницы ограничен сверху, чтобы SQL-смещение помещалось в число SQLite.
Организации отсортированы по ID. Новая организация имеет статус `new`.
